---
title: "Reliability analysis"
---

Use reliability analysis when you want to evaluate internal consistency of a scale.

## What this analysis does

- Estimates reliability coefficients (for example Cronbach's alpha).
- Provides item diagnostics to identify weak items.
- Helps you refine and report multi-item scales.

## Set up the analysis

1. Prepare your data
- Use items intended to measure the same construct.
- Reverse-code items where needed before analysis.

## What the output means

- Start with the overall reliability coefficient.
- Use item diagnostics to identify problematic items.
- Keep theoretical meaning in mind before removing items.
