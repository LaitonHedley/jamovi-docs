title: "Reliability analysis"
---

How to perform a reliability analysis in jamovi:

1.  You need item variables that are intended to measure the same construct.
	Example: a questionnaire scale with several Likert-type items measuring one trait.

	A correct setup should look similar to this:

	{/* TODO: Add data-format screenshot */}
	{/* <img src="/images/jg_data_format_reliability.png" alt="data_format_reliability" style="width: 40.0%" /> */}

2.  Select `Analyses` -> `Factor` -> `Reliability Analysis`.

	{/* TODO: Add menu screenshot */}
	{/* <img src="/images/jg_select_reliability.png" alt="select_reliability" style="width: 40.0%" /> */}

3.  Drag your scale items into the `Variables` box.

	{/* TODO: Add setup screenshot */}
	{/* <img src="/images/jg_add_var_reliability.png" alt="add_var_reliability" style="width: 70.0%" /> */}

4.  In the options panel, tick the reliability coefficient(s) you want to report and any item diagnostics you need.

	{/* TODO: Add options screenshot */}
	{/* <img src="/images/jg_options_reliability.png" alt="options_reliability" style="width: 70.0%" /> */}

5.  The result is shown in the right panel. Start with the overall reliability coefficient, then use the item diagnostics to see whether any items are weakening the scale.
