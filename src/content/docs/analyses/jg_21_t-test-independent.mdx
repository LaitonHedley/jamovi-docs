---
title: "t-test: Independent samples"
---

Use an independent samples t-test to compare the mean of one continuous variable between two independent groups.

In this example, we have a data set of a between subjects manipulation where some mice were randomly allocated to be given either caffeine or a control dose of water.

test whether mice that received caffeine ran farther than mice in a control group.

:::note[Follow-along example]
- Download the starting dataset: [Caffeinated_Mice.csv](/output/Caffeinated_Mice.csv)

:::

## Run the analysis

1.  Open `Caffeinated_Mice.csv` in jamovi and check that the variables are set up correctly.

    You need:

    - one <img src="/images/variable-continuous.svg" alt="continuous measure icon" style="width: 16px" /> continuous dependent variable: `Distance (Meters)`
    - one <img src="/images/variable-nominal.svg" alt="nominal measure icon" style="width: 16px" /> grouping variable with two levels: `Condition` (`Caffeine` and `Control`)

    Your data should be arranged like this:

    <img src="/images/jg_data_format_ttest_independent.jpg" alt="Data with one continuous outcome and one two-level grouping variable" style="width: 60.0%" />

2.  Select `Analyses` → `T-Tests` → `Independent Samples T-Test`.

    <img src="/images/jg_select_ttest_independent.jpg" alt="Opening the Independent Samples T-Test from the Analyses menu" style="width: 60.0%" />

3.  Drag `Distance (Meters)` to `Dependent Variables` and `Condition` to `Grouping Variable`.

    <img src="/images/jg_add_var_ttest_independent.jpg" alt="Assigning Distance as dependent variable and Condition as grouping variable" style="width: 70.0%" />

4.  Select the options you need.

    Under `Additional Statistics`, select `Descriptives` and `Descriptive plots` to show the group means and a plot. Select confidence intervals and effect sizes if needed.

    Under `Assumption Checks`, select `Normality test` and `Equality of variances test`.

    Under `Hypothesis`, select `Group 1 > Group 2` to test whether caffeine makes mice run farther than the control group. This is a one-tailed test.

    <img src="/images/jg_options_ttest_independent.jpg" alt="Independent samples t-test options in jamovi" style="width: 70.0%" />

5.  Read the output.

    Start with the descriptive statistics table. The caffeine group ran farther on average than the control group. The descriptive plot shows the same pattern.

    <img src="/images/jg_options_ttest_desc.jpg" alt="Comparing Means in jamovi via descriptive statstics table and figure" style="width: 70.0%" />

    In the `Independent Samples T-Test` table, check the `p` value. A value below `.05` indicates evidence of a difference between the group means. Here, `p < .001`, supporting the conclusion that the caffeine group ran farther.

    <img src="/images/jg_output_ttest_infe.jpg" alt="testing for significant effect with inferental table" style="width: 70.0%" />

:::note
Check the hypothesis note below the `Independent Samples T-Test` table to see which categories jamovi used as Group 1 and Group 2.
:::

6.  Check the assumptions.

    Confirm that your study has one continuous outcome, two independent groups, and one observation per mouse. Check these from your study design, not the output.

    In the `Normality Test` table, a Shapiro–Wilk `p` value above `.05` means there is no evidence of non-normal data. Here, `p = .478`, so this assumption is met.

    In the `Homogeneity of Variances Test` table, Levene's `p` value above `.05` means the groups have similar variability. Here, `p = .549`, so the equal-variances assumption is met.

    <img src="/images/jg_output_ttest_assumptions.jpg" alt="Normality Test and Homogeneity of Variances Test tables showing the assumption checks for the independent samples t-test" style="width: 70.0%" />


:::tip
If you have previous experience with SPSS, see the [side-by-side comparison](/spss2jamovi/s2j_ttestis) of how an independent samples t-test is run in SPSS and jamovi.
:::


7.  Write up the results.

    An independent-samples *t* test was used to compare if mice given caffeiene ran further than mice in the control group.
    Mice in the caffeiene group (*M* = 72.8, *SD* = 13.4) ran significantly farther than mice in the control group (*M* = 44.3, *SD* = 11.3), *t*(18) = 5.15, *p* < .001.
    All assumptions were met.
