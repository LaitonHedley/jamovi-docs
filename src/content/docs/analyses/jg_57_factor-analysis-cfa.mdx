---
title: "Confirmatory Factor Analysis (CFA)"
---

How to perform a confirmatory factor analysis in jamovi:

1.  You need item variables that are expected to measure specific latent constructs (typically <img src="/images/variable-ordinal.svg" alt="ordinal" style="width: 16px; vertical-align: middle" /> ordinal or <img src="/images/variable-continuous.svg" alt="continuous" style="width: 16px; vertical-align: middle" /> continuous responses).
	Example: Depression Anxiety Stress Scale (DASS) 21-item version, with three latent factors (Depression, Anxiety, Stress) and a four-category ordered response scale.

	A correct setup should look similar to this:

	<img src="/images/jg_data_format_factor_analysis_cfa.png" alt="data_format_factor_analysis_cfa" style="width: 70.0%" />

2.  Select `Analyses` -> `Factor` -> `Confirmatory Factor Analysis`.

	<img src="/images/jg_select_factor_analysis_cfa.png" alt="select_factor_analysis_cfa" style="width: 70.0%" />

3.  Define your factors by naming each latent factor (for example, Depression, Anxiety, and Stress).

	<img src="/images/jg_label_factor_analysis_cfa.png" alt="label_factor_analysis_cfa" style="width: 70.0%" />

4.  Move the item variables into the variable box and specify which items should load onto each factor.

	<img src="/images/jg_add_var_factor_analysis_cfa.png" alt="add_var_factor_analysis_cfa" style="width: 70.0%" />

5.  The result is shown in the right panel.

    Check the Factor Loadings table to see how strongly each questionnaire item is associated with the underlying factor it is intended to measure:
	<img src="/images/jg_output_factor_analysis_cfa.png" alt="output_factor_analysis_cfa" style="width: 50.0%" />

	Use the fit indices to judge how well the model fits.
	<img src="/images/jg_model_fit_factor_analysis_cfa.png" alt="model_fit_factor_analysis_cfa" style="width: 45.0%" />
