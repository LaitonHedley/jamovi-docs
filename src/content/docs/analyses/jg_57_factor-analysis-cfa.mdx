---
title: "Confirmatory factor analysis (CFA)"
---

Use confirmatory factor analysis when you want to test whether a hypothesized factor model fits your data.

## What this analysis does

- Tests a predefined latent-factor structure.
- Evaluates model fit using fit indices.
- Estimates standardized factor loadings.

## Set up the analysis

1. Prepare your data
- Use item variables that are linked to specific latent constructs.
- Define your expected model before running the analysis.

- Use fit indices to evaluate overall model fit.
- Inspect standardized loadings to assess item-factor relationships.
- Revise models cautiously and report all model changes transparently.
