Use this analysis when you want to test whether observed category counts match expected proportions.

## What this analysis does

- Produces one-way frequency counts for a categorical variable.
- Runs a chi-square goodness-of-fit test.
- Tests whether observed counts differ from expected counts.

## Set up the analysis

1. Prepare your data
- Use one categorical variable.
- Make sure each row is one case, or provide a count variable if needed.

2. Open the analysis in jamovi

3. Assign variables
- Move your categorical variable into the variable box.
- If required, enter expected proportions for each category.

4. Choose key options
- Tick `Chi-square` statistics.
- Request effect size or residual information if available.
- Confirm expected proportions sum correctly.

## What the output means

- Compare observed and expected counts across categories.
- Use the chi-square p-value to decide whether differences are larger than chance.
- Report the chi-square statistic, degrees of freedom, p-value, and sample size.
