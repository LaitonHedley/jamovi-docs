---
title: "Exploratory Factor Analysis (EFA)"
---

How to perform an exploratory factor analysis in jamovi:

1.  You need item variables that are expected to measure shared constructs (typically <img src="/images/variable-ordinal.svg" alt="ordinal" style="width: 16px; vertical-align: middle" /> ordinal or <img src="/images/variable-continuous.svg" alt="continuous" style="width: 16px; vertical-align: middle" /> continuous responses).
    Example: 12 items with 5-point Likert responses, testing how the items load onto an unknown number of factors.

    A correct setup should look similar to this:
	<img src="/images/jg_data_format_factor_analysis.png" alt="data_format_factor_analysis" style="width: 70.0%" />

2.  Select `Analyses` -> `Factor` -> `Exploratory Factor Analysis`.

	<img src="/images/jg_select_factor_analysis.png" alt="select_factor_analysis" style="width: 70.0%" />

3.  Drag your item variables into the variable box.

	<img src="/images/jg_add_var_factor_analysis.png" alt="add_var_factor_analysis" style="width: 70.0%" />

4.  In the options panel, choose an appropriate extraction and rotation method, and tick Scree plot.

	<img src="/images/jg_options_factor_analysis.png" alt="options_factor_analysis" style="width: 70.0%" />

5.  The result is shown in the right panel. Use the scree plot to help decide how many factors to retain, then use the loadings to see which items define each factor.

	<img src="/images/jg_scree_factor_analysis.png" alt="scree_factor_analysis" style="width: 70.0%" />

	<img src="/images/jg_output_factor_analysis.png" alt="output_factor_analysis" style="width: 70.0%" />
