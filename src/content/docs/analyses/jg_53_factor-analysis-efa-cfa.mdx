---
title: "Exploratory factor analysis (EFA)"
---

Use exploratory factor analysis when you want to identify latent factor structure from observed items.

## What this analysis does

- Identifies how items cluster into factors.
- Helps you decide how many factors to retain.
- Supports early-stage scale development and construct exploration.

## Set up the analysis

1. Prepare your data
- Use item-level variables that are expected to measure common constructs.
- Use a sample size suitable for factor analysis.

- Request loading tables and diagnostics.

## What the output means

- Inspect factor loadings to identify which items define each factor.
- Use retention and diagnostic outputs to justify the number of factors.
- Report extraction, rotation, and factor-retention decisions clearly.
