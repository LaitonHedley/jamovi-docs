title: "From SPSS to jamovi: Non-parametric analyses"
---

This comparison shows how a Mann-Whitney test is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 7.4.3 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 7.6 - 7.8 and output 7.2. It uses the data set **Drug.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td>In SPSS, the first table is the <code>Hypothesis Test Summary</code>, which only shows the significance value. If you double-click this table you open the model viewer window, which contains the details of the analysis. To view the results for the Wednesday sample, select <code>Beck Depression Inventory (Wednesday) \* Type of Drug(Test 2)</code> in the drop-down menu next to <code>Field(s)</code>.</td>
<td>In jamovi, results are presented in the <code>Independent Samples T-Test</code> table. Here the <em>U</em>-value is found in the first column, and its significance level in the second column.</td>

<tr>
<td colspan="2"><p>The output in jamovi only presents the Mann-Whitney U statistic and its significance value, while SPSS presents values for <code>Mean Rank</code>, <code>N</code>, <code>Total N</code>, <code>Wilcoxon W</code>, <code>Test Statistic</code>, <code>Standard Error</code>, <code>Standardized Test Statistic</code> and <code>Asymptotic Sig. (2-sided test)</code>.</p>
<p>The numerical values for the Wednesday group are the same in SPSS and jamovi (<em>U</em> = 4.00, <em>p</em> &lt; .001), while the values for the Sunday group differ slightly (<em>U</em> = 35.50, <em>p</em> = .280 vs. <em>p</em> = .286). The reason for the difference is that jamovi applies <a href="https://www.oxfordreference.com/view/10.1093/oi/authority.20110803100131510">continuity correction</a> (where a discrete distribution – ranks – is approximated via a continuous one – the standard normal distribution) whereas SPSS doesn't.</p></td>
</tr>
