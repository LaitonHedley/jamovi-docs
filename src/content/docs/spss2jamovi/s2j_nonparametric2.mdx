title: "From SPSS to jamovi: Non-parametric analyses"
---

This comparison shows how a Wilcoxon signed-rank test is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 7.5.2 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 7.9 and output 7.3 - 7.4. It uses the data set **Drug.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td>In SPSS, first split the file using <code>Data</code> → <code>Split File</code>.</td>
<td rowspan="3">In jamovi, the <code>FILTER()</code>-function can be used to achieve a split. You need to create two new computed variables (ideally, those variables should be inserted before <code>Wednesay_BDI</code>). For the first, use <code>FILTER(Sunday_BDI, Drug == "Ecstasy")</code> as expression to be calculated and name the variable <code>Sunday_BDI_Ecstasy</code>. For the second, use <code>FILTER(Sunday_BDI, Drug == "Alcohol")</code> as expression and <code>Sunday_BDI_Alcohol</code> as name. Please note, that it is not necessary to split the second variable <code>Wednesday_BDI</code> since jamovi uses listwise exclusion.</td>

<td colspan="2">When comparing the output, none of the numerical values for the test statistic are the same. The reason for the difference in p-values is that jamovi applies <a href="https://www.oxfordreference.com/view/10.1093/oi/authority.20110803100131510">continuity correction</a> (where a discrete distribution – ranks – is approximated via a continuous one – the standard normal distribution) whereas SPSS doesn't.</td>
</tr>
