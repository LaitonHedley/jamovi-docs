---
title: "From SPSS to jamovi: Linear regression"
---

This comparison shows how a linear model with one predictor is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 9.7 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 9.13, and output 9.2-9.4. It uses the data set **Album Sales.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<tr>
<td>The table Model Summary shows the value of <em>R</em> (= .578) and <em>R²</em> (= .335) for model. The most important part of the ANOVA table is the value of <em>F</em> (= 99.587), and its significance <em>p</em> (&lt; .001). This shows that this model this model predicts album sales significantly. The Coefficients table shows the beta values and significance of these values.</td>
<td>In jamovi, <em>R</em> and <em>R²</em> are found in the table called Model Fit Measures. The results from the ANOVA is found in the table called Omnibus ANOVA Test, and the beta values are found in the table Model Coefficients – Sales. In jamovi, the beta value is found in the section called Stand. Estimate, which is located at the far right of the table. As this analysis only has one predictor, the <em>R</em> value is the correlation between advertising and album sales. Furthermore, the value of <em>R²</em> indicates that money spent on advertising can account for 33.5% of the variance in sales of albums.</td>
</tr>
