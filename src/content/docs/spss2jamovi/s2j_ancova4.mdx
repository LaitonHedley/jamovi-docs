title: "From SPSS to jamovi: Analysis of Covariance (ANCOVA)"
---

This comparison shows how an analysis of covariance which excludes the covariate is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 13.6.1 - 13.6.4 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 13.5 - 13.7 (excluding the covariate in figure 13.5 and `Options` in figure 13.7) and output 13.5. It uses the data set **Puppy Love.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<tr>
<td>In SPSS, you can find the adjusted values of the group means in the <code>Estimates</code> table. By looking at the <code>Mean</code> you can find out if there are any changes in happiness levels if there is an increase in puppy exposure. The <code>Tests of Between-Subjects Effects</code> table shows the sum of squares for the dose of puppies, and this tells us how many units of variance this factor accounts for. In the <code>Contrast Results (K Matrix)</code> table, level 2 (15 mins) is compared with level 1 (control) and then level 3 (30 mins) is compared with level 1 (control). Here, the group differences are indicated by standard error, a difference value and a <em>p</em>-value.</td>
<td>In jamovi, the adjusted values can be found in the table called <code>Estimated Marginal Means – Dose</code>. This table looks exactly the same as the equivalent table in SPSS. Sum of squares are found in the <code>ANCOVA – Happiness</code> table. These tables differ slightly in SPSS and in jamovi, as jamovi only gives results for <code>Dose</code>, <code>Puppy_love</code> and <code>Residuals</code>. The contrast analysis in jamovi also does not provide all of the values that the SPSS analysis does. However, all important information (that you typically would report) is included.</td>
</tr>
<tr>
<td colspan="2"><p>jamovi does not include the values for the <code>Corrected Model</code>, <code>Intercept</code>, <code>Total</code> and <code>Corrected Total</code> in its analysis of covariance. Apart from this, the ANCOVA table follows the same structure as in SPSS. The tables for <code>Estimated Marginal Means</code> are also identical in SPSS and jamovi. The results from the contrast analysis in jamovi appears much clearer than the one in SPSS. Here, the results are presented horizontally, while the results in SPSS are presented vertically. In contrast to SPSS, jamovi only includes the following values: <code>Estimate</code>, <code>SE`,</code><em>t</em><code>and</code><em>p</em>``.</p>
<p>The numerical values for these analyses are the same: <em>SS</em>&lt;sub&gt;Dose&lt;/sub&gt; = 16.84; <em>M</em>&lt;sub&gt;Control&lt;/sub&gt; = 3.22, <em>M</em>&lt;sub&gt;15mins&lt;/sub&gt; = 4.87, <em>M</em>&lt;sub&gt;30mins&lt;/sub&gt; = 4.85; contrast 1, <em>p</em> = 0.080; contrast 2, <em>p</em> = 0.055.</p></td>

<tr>
<td><pre class="none"><code>UNIANOVA Happiness BY Dose
  /CONTRAST(Dose)=Simple(1)
  /METHOD=SSTYPE(3)
  /INTERCEPT=INCLUDE
  /EMMEANS=TABLES(Dose) COMPARE ADJ(SIDAK)
  /CRITERIA=ALPHA(0.05)
  /DESIGN=Dose.</code></pre></td>
<td><pre class="none"><code>jmv::ancova(
    formula = Happiness ~ Dose,
    data = data,
    contrasts = list(list(var = &quot;Dose&quot;, type = &quot;simple&quot;)),
    emMeans = ~ Dose,
    emmPlots = FALSE,
    emmPlotError = &quot;none&quot;,
    emmTables = TRUE)</code></pre></td>
</tr>
