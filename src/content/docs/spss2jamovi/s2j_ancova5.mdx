---
title: "From SPSS to jamovi: Analysis of Covariance (ANCOVA)"
---

This comparison shows how to test the assumption of homogeneity of regression slopes in SPSS and jamovi. The SPSS test follows the description in chapter 13.7 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 13.9 and output 13.12. It uses the data set **Puppy Love Dummy.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td colspan="2"><p>The main difference between the results in SPSS and jamovi is that SPSS provides values for the following: <code>Corrected Model</code>, <code>Intercept</code>, <code>Total</code> and <code>Corrected Total</code>. SPSS also gives <em>R²</em> and adjusted <em>R²</em> values for the corrected model.</p>
<p>If one compares the numerical values, they are the same: <em>SS</em>&lt;sub&gt;Dose&lt;/sub&gt; = 36.6, <em>p</em> &lt; .01; <em>SS</em>&lt;sub&gt;Puppy_love&lt;/sub&gt; = 17.2, <em>p</em> &lt; .05; <em>SS</em>&lt;sub&gt;Dose * Puppy_love&lt;/sub&gt; = 20.4, <em>p</em> &lt; .05.</p></td>

  /CRITERIA=ALPHA(0.05)
  /DESIGN=Dose\*Puppy_love Dose Puppy_love.</code></pre></td>
