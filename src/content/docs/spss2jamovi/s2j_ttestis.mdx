---
title: "From SPSS to jamovi: t-test for independent samples"
---

This comparison shows how a t-test for independent samples is performed in SPSS and jamovi. How the test is conducted in SPSS follows the description in chapter 10.8 of [Field (2017)](https://edge.sagepub.com/field5e), especially Figure 10.4 and Output 10.3 - 10.4. It uses the data set **Invisibility.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td>In SPSS, <code>Mischevious acts</code> is moved to the variable box <code>Test variables(s)</code> and <code>Cloak of invisibility</code> to variable box <code>Grouping variables</code>. Afterwards, press the button <code>Define Groups...</code> (underneath the variable box <code>Grouping variables</code>) and enter <code>0</code> under <code>Group 1</code> and <code>1</code> under <code>Group 2</code>.</td>
<td>In jamovi, the variable <code>Mischief</code> is moved to the variable box <code>Dependent Variable(s)</code>, and the variable <code>Cloak</code> is moved to the variable box <code>Grouping Variable</code>. If you wish to obtain an identical output to SPSS, one has to switch on the Levene's Test for the Equality of Variances, by ticking <code>Homogeneity Test</code> under <code>Assumption Checks</code>; the table with the descriptive statistics for the two groups can be selected by ticking <code>Descriptives</code> under <code>Additional Statistics</code>.</td>

<tr>
<td>In SPSS, the output table <code>Independent Samples T-Test</code> starts with Levene's Test for the Equality of Variances. If it is NOT significant (p &gt; 0.05), one can use the results from the first line (<code>Equal variances assumed</code>), otherwise, you have to use the results from the second line (<code>Equal variances not assumed</code>).</td>
<td>If the p-value in the table <code>Homogeneity of Variances Test (Levene's)</code> is significant (p &lt; 0.05), then you have to correct for that inhomogeneity. To do so, untick <code>Student's</code> and tick <code>Welch's</code> instead (under <code>Test</code> in the input panel). The results described underneath can be found in the first table <code>Independent Samples T-Test</code>.</td>
</tr>
<tr>
<td colspan="2"><p>The t-value can be found in the third column (<code>t</code>) in SPSS and the first column (<code>statistics</code>) in jamovi, the next column after that (<code>df</code>, both in SPSS and jamovi) shows the degrees of freedom and the column after that (<code>Sig. (2-tailed)</code> in SPSS, <code>p</code> in jamovi) the p-value for this combination of t-value and degrees of freedom.</p>
<p>The numerical values for the statistics are identical: <em>t</em> = -1.71, <em>df</em> = 22, <em>p</em> = 0.101.</p></td>
</tr>
