---
title: "From SPSS to jamovi: Analysis of Covariance (ANCOVA)"
---

This comparison shows how a regression with one predictor and two dummy variables is performed in SPSS and jamovi. The SPSS test follows the description in chapter 13.3 of [Field (2017)](https://edge.sagepub.com/field5e), especially Output 13.1 - 13.2. It uses the data set **Puppy Love Dummy.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<tr>
<td>In SPSS, the output table <code>Model Summary</code> starts with <em>R</em> and <em>R²</em>. The <em>R²</em>-value for model 1 shows the goodness of fit when only the covariate is included in the analysis, and the value for model 2 shows the results when the dummy variables and the covariate are included. The <code>ANOVA</code> table presents the sum of squares for the regression, which tells us how many units of variance the model accounts for. The most interesting table is the <code>Coefficients</code> table, where you can find the differences in <em>b-</em>values and <em>β</em>-values for the two models, as well as their significance values.</td>
<td>In jamovi, the <em>R</em>and <em>R²</em>-values are found in the output table <code>Model Fit Measures</code>. The Sum of Squares and <em>F</em>-values are found in the <code>Omnibus ANOVA Test</code> table, which in jamovi is separated into a table for model 1 and a table for model 2. Nonetheless, the numbers appear in the same place in the tables. The <code>Coefficients</code> table is also divided into two tables - one for each model – in jamovi. Here the <em>b</em>-values are found under Estimate and the the <em>β</em>-values under Stand. Estimate.</td>
</tr>
<tr>
<td colspan="2"><p>The <em>R</em>and <em>R²</em>-values are found in the first and second column in the first output table in both SPSS and jamovi. In contrast to SPSS, jamovi splits the <code>ANOVA</code> and <code>Coefficients</code> for model 1 and model 2. Despite this, almost all the values are found in the same columns, except for the <em>β</em>-values, which are located before the <em>t</em>- and <em>p</em>-values in SPSS and after the <em>t</em>- and <em>p</em>-values in jamovi.</p>
<p>The numerical values for the model 2 statistics are identical: <em>R</em> = 0.54, <em>R²</em> = 0.29; <em>b</em> = 0.42, <em>p</em> &lt; .05; <em>β</em> = 0.39, <em>p</em> &lt; .05.</p></td>
</tr>

<tr>
<td><pre class="none"><code>REGRESSION
  /MISSING LISTWISE
  /STATISTICS COEFF OUTS R ANOVA
  /CRITERIA=PIN(.05) POUT(.10)
  /NOORIGIN
  /DEPENDENT Happiness
  /METHOD=ENTER Puppy_love
  /METHOD=ENTER Low_Control High_Control.</code></pre></td>
<td><pre class="none"><code>jmv::linReg(
    data = data,
    dep = Happiness,
    covs = Puppy_love,
    factors = vars(Low_Control, High_Control),
    blocks = list(
        list(&quot;Puppy_love&quot;),
        list(&quot;Low_Control&quot;, &quot;High_Control&quot;)),
    refLevels = list(
        list(var=&quot;Low_Control&quot;, ref=&quot;0&quot;),
         list(var=&quot;High_Control&quot;, ref=&quot;0&quot;)),
    anova = TRUE)</code></pre></td>
