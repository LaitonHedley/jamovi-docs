---
title: "File Menu: Save As"
---

Select `Save As` to save a copy with a new name or in a new location.

Use this when you want to keep the original file unchanged.

<img src="/images/ur_file_menu_save_as_option.png" alt="The Save As option in the jamovi File menu" style="width: 50%" />

After selecting `Save As`, choose where you want to save the file.

<img src="/images/ur_file_menu_save_as_location.png" alt="Choosing a save location in the Save As dialog" style="width: 100%" />

Enter a file name, then click `Save`.

<img src="/images/ur_file_menu_save_as_filename.png" alt="Entering a file name in the Save As dialog" style="width: 100%" />

jamovi saves the new file and keeps it open in the spreadsheet.

A confirmation message appears in the bottom-right corner to indicate the save was successful.

<img src="/images/ur_file_menu_save_as_saved.png" alt="The saved file opened in the jamovi spreadsheet" style="width: 100%" />
