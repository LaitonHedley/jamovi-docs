---
title: "File Menu: Open"
---

Select `Open` to open an existing file. jamovi supports jamovi project files (`.omv`) as well as common data formats such as CSV, Excel, SPSS, Stata, and SAS.

<img src="/images/ur_file_menu_open_option.png" alt="The Open option in the jamovi File menu" style="width: 50%" />

Click `This PC` and use the file browser in jamovi to navigate to your data file. Alternatively, select `Browse` to browse files in your computer's native file browser.

<img src="/images/ur_file_menu_open_nav.png" alt="The file browser used to navigate to a data file" style="width: 100%" />

:::note
You can also access jamovi's built-in data library from the Open menu by selecting `Data Library`. These example datasets are useful for learning and practicing analyses.
:::

Click the file you want to open.

<img src="/images/ur_file_menu_open_file_found.png" alt="A selected data file ready to open in jamovi" style="width: 100%" />

The file opens in the jamovi spreadsheet.

<img src="/images/ur_file_menu_open_file_dass.png" alt="An opened data file displayed in the jamovi spreadsheet" style="width: 100%" />
