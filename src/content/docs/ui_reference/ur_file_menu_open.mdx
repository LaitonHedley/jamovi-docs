---
title: "File Menu: Open"
---

Select `Open` to open an existing file.

<img src="/images/ur_file_menu_open_option.png" alt="The Open option in the jamovi File menu" style="width: 40.0%" />

:::note
Open supports jamovi project files (`.omv`) and common data formats such as CSV, Excel, SPSS, Stata, and SAS.
:::

Click `This PC` and use the file browser in jamovi to navigate to your data file. In this example, the file is on the Desktop, so select `Desktop`.

<img src="/images/ur_file_menu_open_nav.png" alt="The file browser used to navigate to a data file" style="width: 70.0%" />

:::note
You can also access jamovi's built-in data library from the Open menu by selecting `Data Library`. These example datasets are useful for learning and practicing analyses.
:::

Click the file you want to open.

<img src="/images/ur_file_menu_open_file_found.png" alt="A selected data file ready to open in jamovi" style="width: 70.0%" />

:::note
Alternatively, select `Browse` to navigate files in your computer's native file browser.
:::

The file opens in the jamovi spreadsheet.

<img src="/images/ur_file_menu_open_file_dass.png" alt="An opened data file displayed in the jamovi spreadsheet" style="width: 70.0%" />
