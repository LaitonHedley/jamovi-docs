The File (hamburger) `☰` is in the top-left corner of jamovi.

Use this menu to manage files in jamovi. This is where you start a new file, open or import data, save your work, and export content for sharing.

<img src="/images/ur_file_menu_button.png" alt="file_menu_button" style="width: 100%" />

These options are available in the File menu: `New`, `Open`, `Import`, `Save`, `Save As`, and `Export`.

<img src="/images/ur_file_menu_look_inside.png" alt="The options shown in the jamovi File menu" style="width: 50%" />

When to use each option:

- `New`: Start a new, blank jamovi file.
- `Open`: Open an existing jamovi file or data file.
- `Import`: Add data from another file into the dataset you already have open.
- `Save`: Save changes to the current file.
- `Save As`: Save a copy with a new name or in a new location.
- `Export`: Export data or results to another format for sharing or reporting.


For more details on each option, see the sections below.
