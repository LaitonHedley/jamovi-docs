The File (hamburger) `☰` is in the top-left corner of jamovi.

<img src="/images/ur_file_menu_button.png" alt="file_menu_button" style="width: 70.0%" />

You can access these options from the File menu

<img src="/images/ur_file_menu_look_inside.png" alt="The options shown in the jamovi File menu" style="width: 40.0%" />

Use these options to create new files, open existing files, import files into an existing dataset, save files, and export files in a range of formats.


For more details on each option, see the sections below.
