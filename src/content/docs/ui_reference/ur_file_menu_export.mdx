---
title: "File Menu: Export"
---

Select `Export` to export data or results in other formats.

For example, you can export reports and share outputs without sharing the full editable jamovi file.

<img src="/images/ur_file_menu_export_option.png" alt="The Export option in the jamovi File menu" style="width: 20.0%" />

After selecting `Export`, choose what you want to export.

<img src="/images/ur_file_menu_export_choose_type.png" alt="Choosing what to export from jamovi" style="width: 50.0%" />

Select the export format and destination location.

<img src="/images/ur_file_menu_export_format_location.png" alt="Selecting export format and destination" style="width: 50.0%" />

Click `Save` to export the file.

<img src="/images/ur_file_menu_export_done.png" alt="An exported file created from jamovi" style="width: 50.0%" />

:::note
Export is useful when you need to share results with people who do not use jamovi.
:::
