---
title: "File Menu: Export"
---

Select `Export` to save data or results in another file format.

<img src="/images/ur_file_menu_export_option.png" alt="The Export option in the jamovi File menu" style="width: 50%" />

After selecting `Export`, choose the save location, enter a file name, choose the file format (below the file name).

<img src="/images/ur_file_menu_export_type_name.png" alt="Choosing file format and naming file" style="width: 70%" />

:::note
jamovi output can be exported to a range of formats, including PDF, Web Page (HTML), jamovi template (OMT), CSV, Open Document (ODS), Excel (XLSX), LaTeX bundle, R object (RDS/RData), SPSS (SAV), SAS (SAS7BDAT/XPT), and Stata (DTA).
:::


Click `Export` next to the floppy disk icon.

<img src="/images/ur_file_menu_export_icon.png" alt="Click Export or floppy disk icon " style="width: 70%" />


A confirmation message appears in the bottom-right corner of jamovi. Your exported file is then ready to share from the saved location.

<img src="/images/ur_file_menu_export_done.png" alt="An exported file created from jamovi" style="width: 100%" />

:::note
If you use a file name that already exists, jamovi asks you to confirm that you want to overwrite it.
:::
