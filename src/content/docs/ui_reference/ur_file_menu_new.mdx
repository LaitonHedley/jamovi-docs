---
title: "File Menu: New"
---

Select `New` to create a new, blank jamovi file.

Use this when you want to start a new data file from scratch.

<img src="/images/ur_file_menu_new.png" alt="The New option in the jamovi File menu" style="width: 40.0%" />

After selecting `New`, jamovi opens a blank spreadsheet where you can begin entering your data.

<img src="/images/ur_file_blank_spreadsheet.png" alt="A blank jamovi spreadsheet after selecting New" style="width: 80.0%" />

Return to [File Menu](/ui_reference/ur_file_menu).

:::note
This blank spreadsheet is the default view when you start jamovi.
:::
