---
title: "File Menu: Import"
---

Select `Import` to bring new data into the current jamovi file while keeping your existing setup (such as variable definitions, transforms, filters, and analyses).

<img src="/images/ur_file_menu_import_option.png" alt="The Import option in the jamovi File menu" style="width: 50%" />

For example, imagine you carried out a t-test on some pilot data and later received a revised version of the same dataset.

Import lets you bring in the new data while keeping your existing analyses, filters, and variable setup intact.

<img src="/images/ur_file_menu_import_pre_data.png" alt="Pilot Data pre-importing updated data file" style="width: 100%" />


Select `Import`, then choose the updated data file you want to import.

<img src="/images/ur_file_menu_import_select_file.png" alt="Selecting a data file to import" style="width: 100%" />

The new data is loaded into the spreadsheet while your analysis setup stays in place, and a confirmation message appears in the bottom-right corner when the import is successful.

<img src="/images/ur_file_menu_import_loaded.png" alt="Imported data loaded in the jamovi spreadsheet" style="width: 100%" />

:::note
Import is useful when you receive an updated version of a dataset and want to keep your existing analysis workflow.
:::
