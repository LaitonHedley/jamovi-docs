---
title: "File Menu: Import"
---

Select `Import` to bring new data into the current jamovi file while keeping your existing setup (such as variable definitions, transforms, filters, and analyses).

Use this when you want to run the same analysis workflow on updated data.

<img src="/images/ur_file_menu_import_option.png" alt="The Import option in the jamovi File menu" style="width: 20.0%" />

After selecting `Import`, choose the data file you want to import.

<img src="/images/ur_file_menu_import_select_file.png" alt="Selecting a data file to import" style="width: 50.0%" />

Confirm the import settings if prompted, then continue.

<img src="/images/ur_file_menu_import_settings.png" alt="Import settings before loading data into jamovi" style="width: 50.0%" />

The new data is loaded into the spreadsheet while your analysis setup stays in place.

<img src="/images/ur_file_menu_import_loaded.png" alt="Imported data loaded in the jamovi spreadsheet" style="width: 50.0%" />

:::note
Import is useful when you receive an updated version of a dataset and want to keep your existing analysis workflow.
:::
