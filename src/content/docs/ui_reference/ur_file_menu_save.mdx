---
title: "File Menu: Save"
---

Select `Save` to save the current jamovi file. You can also use the keyboard shortcut `⌘S` (Mac) or `Ctrl+S` (Windows) to save your work quickly.

<img src="/images/ur_file_menu_save_option.png" alt="The Save option in the jamovi File menu" style="width: 50%" />


Below is a full view of the save option in the user interface.

<img src="/images/ur_file_menu_save_check.png" alt="The Save option in the jamovi File menu alognside directory" style="width: 100%" />


Once save is selected, a confirmation message appears in the bottom-right corner to let you know the save was successful.

After saving, your changes are stored in the .omv file and can be revisited or edited later.

<img src="/images/ur_file_menu_save_done.png" alt="A jamovi file after saving changes" style="width: 100%" />

If you want to keep the original file and save a new copy, use [File Menu: Save As](/ui_reference/ur_file_menu_save_as).

:::note
If the file has not been saved before, jamovi asks you to choose a file name and location.
:::
