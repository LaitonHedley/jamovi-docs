---
title: "File Menu: Save"
---

Select `Save` to save the current jamovi file.

Use this after you make changes to your data, variable setup, analyses, or other content in the file.

<img src="/images/ur_file_menu_save_option.png" alt="The Save option in the jamovi File menu" style="width: 20.0%" />

Select `Save` to update the existing file


If the file has not been saved before, jamovi asks you to choose a file name and location.

After saving, your changes are stored in the file.

<img src="/images/ur_file_menu_save_done.png" alt="A jamovi file after saving changes" style="width: 50.0%" />

If you want to keep the original file and save a new copy, use [File Menu: Save As](/ui_reference/ur_file_menu_save_as).

:::note
You can also use the keyboard shortcut for `Save` to save your work quickly.
:::
