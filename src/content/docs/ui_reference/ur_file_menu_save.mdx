---
title: "File Menu: Save"
---

Select `Save` to save the current jamovi file.

Use this after you make changes to your data, variable setup, analyses, or other content in the file. If the file already has a name and location, `Save` updates that existing file. If the file has not been saved before, jamovi asks you to choose a file name and location.

If you want to keep the original file and save a new copy, use [File Menu: Save As](/ui_reference/ur_file_menu_save_as).

You can also use the keyboard shortcut for `Save` to save your work quickly.

Return to [File Menu](/ui_reference/ur_file_menu).
