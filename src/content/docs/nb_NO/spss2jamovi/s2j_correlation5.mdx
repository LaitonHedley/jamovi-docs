This comparison shows how a semi-partial (or partial) correlation is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 8.5.3 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 8.11 and output 8.5. It uses the data set **Exam Anxiety.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td>In SPSS, you can tell if a correlation is significant by noting the amount of asterisks after the correlation coefficient. The correlation matrix shows the correlation coefficient, the p-value, and the sample size (N).</td>
<td>In jamovi, significant correlations are flagged using one (p &lt; .05), two (p &lt; .01) or three (p &lt; .001) asterisks. This differs from SPSS, where all correlation above p &lt; .01 level is simply marked using two instead of three asterisks.</td>
