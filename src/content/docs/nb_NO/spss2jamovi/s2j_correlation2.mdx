This comparison shows how a Spearman's correlation is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 8.4.3 in [Field (2017)](https://edge.sagepub.com/field5e), especially output 8.2. It uses the data set **The Biggest Liar.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td>In SPSS you can run a correlation using: <code>Analyze</code> → <code>Correlate</code> → <code>Bivariate</code>.</td>
<td>In jamovi you do this using: <code>Analyses</code> → <code>Regression</code> → <code>Correlation Matrix</code>.</td>

<td>In SPSS, move the variables <code>Creativity</code> and <code>Position</code> to the variable box <code>Variables</code>. In addition, tick the box called <code>Spearman</code> under <code>Correlation Coefficients</code>.</td>
<td>In jamovi, move the variables <code>Creativity</code> and <code>Position</code> into the box on the right. <tr>
<td>In SPSS, you can tell if a correlation is significant by noting the amount of asterisks after the correlation coefficient. The correlation matrix shows the correlation coefficient, the p-value, and the sample size (N).</td>
<td>jamovi, in accordance with APA-style, flags significant correlations using one (p &lt; .05), two (p &lt; .01) or three (p &lt; .001) asterisks. In contrast, in SPSS all correlations above p &lt; .01 level are simply marked using two instead of three asterisks.</td>
</tr>

<td colspan="2">As in analysis on the previous page, the correlation coefficient is found both underneath and over the diagonal in SPSS, while in jamovi the coefficient is only shown underneath. The numerical values for the statistics are identical: <em>r</em> = -0.37, <em>p</em> &lt; .01.</td>
