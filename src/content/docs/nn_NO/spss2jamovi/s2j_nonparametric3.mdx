This comparison shows how a Kruskal-Wallis test is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 7.6.4 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 7.13 and output 7.5 - 7.6. It uses the data set **Soya.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<td>In SPSS, you have to double-click the summary table to get all of the results. The significance value of the test is found both in the summary table and in the <code>Independent Samples Test View</code>. You can also find the Kruskal-Wallis statistic and the degrees of freedom here.</td>
<td>The output in jamovi contains two tables - <code>Kruskal-Wallis</code> and <code>Pairwise comparisons – Sperm</code>. The <code>Kruskal-Wallis</code> table includes all the same values that are included in the equivalent table in SPSS, except for the sample number. The pairwise comparison looks quite different than the one in SPSS, and only includes a <em>W</em>-value and a <em>p</em>-value.</td>

<td colspan="2"><p>The <code>Pairwise comparisons</code> tables differ in SPSS and jamovi, but this is likely due to jamovi using a different method to calculate these values than SPSS. <p>The numerical values from the Kruskal-Wallis test are the same in SPSS and jamovi: <em>H</em> = 8.66, <em>df</em> = 3, <em>p</em> = .034.</p></td>
