This comparison shows how a binary logistic regression is conducted in SPSS and jamovi. The SPSS test follows the description in chapter 20.5 - 20.6 in [Field (2017)](https://edge.sagepub.com/field5e), especially figure 20.7 - 20.10 and output 20.1 - 20.5 (bootstrap excluded). It uses the data file **Eel.sav** which can be downloaded from the [web page accompanying the book](https://edge.sagepub.com/field5e/student-resources/datasets).

<tr>
<td>In the output from SPSS you can find tables for <code>Model Summary</code>, <code>Variables in the Equation</code> and <code>Omnibus Tests of Model Coefficients</code> for each of the predictors in the model. The <code>Model Summary</code> tables shows the -2LL value for the model, as well as Cox &amp; Snell R² and Nagelkerke R². In the <code>Omnibus Tests of Model Coefficients</code> tables, χ²-values, degrees of freedom and significance values are found. Lastly, you can find <em>b</em>-values, <em>SE</em>-values, degrees of freedom and significance values in the <code>Variables in the Equation</code> table. This table also shows the odds ratio.</td>
<td>In jamovi, -2LL values, Cox &amp; Snell R² and Nagelkerke R² values for all the predictors are found in the table called <code>Model Fit Measures</code>. χ²-values, degrees of freedom and significance levels are found in the <code>Model Comparisons</code> table. In addition, <em>b</em>-values, <em>SE</em>-values, significance level odds ratio and the confidence interval for it as well as the classification table are shown as separate parts of the output (one for each model). Only one model is shown at a time and the model can be selected by using the drop-down menu next to <code>Model Specific Results</code>.</td>
</tr>

<td colspan="2"><div class="line-block">SPSS produces a lot more output tables (some not shown) than jamovi, not the least due to Field (2017) asking for options that are not available in jamovi.<br />
The numerical values for the results are the same.<br />
Model 1: -2LL = 144.158, χ² = 9.926, df = 1, <em>p</em> = 0.002, <em>R²</em><sub>CS</sub> = 0.084, <em>R²</em><sub>N</sub> = 0.113, corr.<sub>NC</sub> = 66.667, corr.<sub>C</sub> = 63.077<br />
Model 2: -2LL = 144.156, χ² = 9.928, df = 2, <em>p</em> = 0.007, <em>R²</em><sub>CS</sub> = 0.084, <em>R²</em><sub>N</sub> = 0.113, corr.<sub>NC</sub> = 66.667, corr.<sub>C</sub> = 63.077<br />
Model 3: -2LL = 144.095, χ² = 9.989, df = 3, <em>p</em> = 0.019, <em>R²</em><sub>CS</sub> = 0.085, <em>R²</em><sub>N</sub> = 0.114, corr.<sub>NC</sub> = 66.667, corr.<sub>C</sub> = 63.077<br />
It becomes clear that <code>Intervention</code> is the most decisive predictor whereas <code>Duration</code> and the interaction of <code>Intervention × Duration</code> don't really lead to better prediction: The number of correctly classified cases doesn't change between the models while Model 1 is the most parsimonuous; furthermore, the Deviance (-2LL) and χ² for Model 2 and 3 are more or less the same as for Model 1 (and since more df's are used in Model 2 and 3, the p-values increase (which is all emphasizing that Model 1 is the best model and should be selected).</div></td>

<tr>
<td><pre class="none"><code>LOGISTIC REGRESSION VARIABLES Cured
   /METHOD=ENTER Intervention
   /METHOD=ENTER Duration
   /METHOD=ENTER Duration * Intervention
   /CONTRAST (Intervention)=Indicator(1)
   /SAVE=PRED PGROUP COOK LEVER DFBETA ZRESID
   /CLASSPLOT
   /CASEWISE OUTLIER(2)
   /PRINT=GOODFIT ITER(1) CI(95)
   /CRITERIA=PIN(0.05) POUT(0.10) ITERATE(20) CUT(0.5).</code></pre></td>
<td><pre class="none"><code>jmv::logRegBin(
    data = data,
    dep = Cured,
    covs = vars(Duration, Intervention),
    blocks = list(list(&quot;Intervention&quot;),
                  list(&quot;Duration&quot;),
                  list(c(&quot;Duration&quot;, &quot;Intervention&quot;))),
    refLevels = list(list(var=&quot;Cured&quot;, ref=&quot;Not Cured&quot;)),
    pseudoR2 = c(&quot;r2mf&quot;, &quot;r2cs&quot;, &quot;r2n&quot;))</code></pre></td>
